# Q-STPP v15 (real data) — combined results, all SEA countries

Fair SOP comparison (mh / grover-inspired / qaoa-inspired), run on real
OpenDengue-derived admin1-month events per country. See
`quantum-dengue-stpp/run_q_stpp_v15_real.py` for the honest scope note
(real dates + region-month occurrence, PROXY spatial coordinates).

Each country folder here has its own `real_comparison_results.json` +
`real_comparison_plot.png` + `run_log.txt` (full console output).

## Caveats

- **Singapore**: this dataset has only 1 admin1 region for Singapore, so every event shares the same (proxy) spatial coordinate. With no spatial variation, *every* permutation preserves L(r) exactly by construction -- the near-zero error for all three methods is a mathematical degeneracy of single-region geography, not a finding about method quality.
- **Timor-Leste**: only 30 real events available in the full record (2005-2005) -- the N=60 and N=120 tiers reuse the same ~30 events as N=30, they are not a larger sample.

- Spatial coordinates everywhere are a **proxy** (country centroid + fixed per-region jitter), not real admin1 geography -- see the script docstring. Only the relative comparison between the three methods on identical points is meaningful.
